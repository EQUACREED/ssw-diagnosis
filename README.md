# 特定技能の支援コスト診断

株式会社エクアクリードによる、特定技能1号の支援委託費と、自社支援にした場合の費用目安を、ブラウザ内で計算する診断ページです。

- 診断の計算は、入力した金額と時間の目安だけで行います。サーバーへは自動では送りません。
- 結果は概算です。要件の最終判断には、個別の確認が必要です。
- 予約は [Googleカレンダーの予約ページ](https://calendar.google.com/appointments/schedules/AcZssZ149mwnPuYoTvcSm0ElB1hPXJ0OCavC5LjCwldmn9G_XsJGDKeOMsFFhB8siRCN4ces_oqRJdcH) からできます。
- 連絡先は [公式LINE](https://lin.ee/vRRtEW9) と [Instagram](https://www.instagram.com/equa_creed/) です。
- [個人情報の扱い（下書き）](privacy.html) を公開しています。この文面は最終確認前です。

「診断結果を送って相談する」の送信機能は、準備が整い次第、このページから使えるようにします。いまは診断と予約の案内までご利用ください。
